⚙ Data connection & lead notification setup

1. Connect your real MLS feed

Contact Baldwin REALTORS® (BCMLS) and/or Gulf Coast Mobile Assn MLS and request RESO Web API (or IDX) credentials for your account. Once issued, replace the fetchListings() function in this file's code with a fetch call to your MLS's RESO endpoint — the listing card fields (price, beds, baths, sqft, city, status, MLS#) are already named to match standard RESO fields, so it's mostly a data-mapping job, not a redesign.

If you'd rather not edit code yourself, this is a well-defined task to hand to a developer or to Claude Code — the mock data structure at the top of the file (MOCK_LISTINGS) shows exactly what shape real data should arrive in.

2. Get leads emailed to you

Checking email notification status…

This is configured directly on the server (not here in the browser) using your own Gmail account — set the GMAIL_USER, GMAIL_APP_PASSWORD, and NOTIFY_EMAIL values in your hosting provider's environment variables / secrets. No third-party email service needed.

Until this is set up, every lead is still saved and visible in this CRM the moment it comes in — you just won't get an email yet.

3. Free listing views before sign-up

Visitors can view this many listings free before we ask them to create a free account (which becomes a lead automatically). Once they create an account, browsing is unlimited on that device.
